# AZAKEI CITY

1964→2022。60年の経済を、街ごと生き抜け。

**▶ 遊ぶ：https://azakeiten.github.io/azakei-city/**

ブラウザだけで遊べます。ログインもインストールも要りません。スマホでもPCでも遊べます。

## どんなゲーム？

市場からカードを1枚とって、街に建物を建てる。建物の稼ぎは「となり次第」。8手ごとに時代が進み、東京オリンピック、オイルショック、バブル、リーマン・ショック…本当の経済の出来事が街を襲います。

覚えるのは3つだけ。

1. **1枚とって、建てる** — 市場の5枚から1枚。建物の上下左右に置く
2. **となりで稼ぎが変わる** — 置く前に、増えるスコアがマスに出る
3. **8手ごとに決算** — 稼ぎを受け取る。稼ぎ2以下の会社は倒産

## 遊び方いろいろ

- **ひとりで** — CPUの社長2人と対戦（強さは3段階）
- **友だちと** — 1台を順番に回して2〜4人
- **ショート** — 大事件の6時代だけ
- **チャレンジ** — 歴史の一場面（全8ステージ）をひとりで攻略して★を集める
- **今日の街** — その日はみんな同じ市場。点数で勝負

ほかに、立体の街に直接建てられる盤面（平面にも切りかえ可）、時代ごとのBGM、時代レース、会社の名前（「六本木銀行」など）、ゲームごとにちがう地図（川と駅）、名所づくり、時代のお題、買収、政策会議、4つの社長タイプ（ライオン・キツネ・カメ・ウサギ）、社長ごとの「ひみつの目標」（2枚から選ぶ・ライバルの目標の予想も）、時代で変わる天気（不景気は雨、好景気は花火）、遊ぶほど上がる社長ランクと、ランクで解放される街のテーマ（桜・雪・ネオン）、ホーム画面に浮かぶ自分の街、試合のふりかえり（スコアの折れ線グラフと名場面）、自己ベストと通算記録、CPUライバルとの対戦成績、決算で飛ぶコイン、トップ交代やラスト1時代を知らせる実況テロップ、建物をタップすると出る会社カード（創業年・成長の歴史・老舗）、あなたの最強企業と殿堂入り企業、新聞の「その頃の数字」（ドル円・初任給）と時代クイズ、毎日3つの「今日のミッション」、時代が変わるときの年号めくり、名前を変えられる自分の街（「六本木市」など）、時代の途中に入る「速報」、60年の経済を年表とグラフで読める「経済ミュージアム」、CPUの番の早送り、車が走り雲が流れる立体の街、社長手帳（バッジ）、絵でわかるルールブックがあります。

## つくった人

[AZAKEI（麻経）](https://azakeiten.github.io/) — 麻布中学校・高等学校の経済系同好会

NEWSの点数は、AZAKEI MARKET 歴史モードと同じです。点数は、実際の出来事でその産業が追い風だったか向かい風だったかをもとに、ゲーム用に決めたものです。
